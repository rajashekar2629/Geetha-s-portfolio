# Geetha Gangavath – Portfolio

Personal portfolio website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` – page content
- `style.css` – colors, layout and animations
- `script.js` – photo card flip and footer year
- `images/profile.jpg` – profile photo

## Run locally

Open `index.html` in any browser.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Open the repository, then Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select the `main` branch and the `/ (root)` folder, then Save.
4. After a minute the site appears at `https://<username>.github.io/<repository-name>/`.
